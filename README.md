# Vision Market Agent

MVP web app skeleton for a crypto market analysis dashboard powered by a future AI neuron math engine.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Server-side API routes
- Recharts-ready UI structure
- Mock data only for the first MVP stage

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## MVP scope

This first stage intentionally avoids real exchange/API integrations. The focus is project setup, clean structure, layout, dashboard skeleton, and mock data that is easy to debug.

## Routes

- `/`
- `/dashboard`
- `/coin/[symbol]`
- `/settings`
